# Journzy plugin

This repository publishes the Journzy plugin: read-only help with your Journzy books for your AI
assistant. The plugin is in [`plugins/journzy`](plugins/journzy); its README says what it does,
how to use it and what data it sends.

Install it in Claude Code:

```bash
claude plugin marketplace add obsurvive/journzy-plugin
claude plugin install journzy@journzy
```

This repository is generated from Journzy's private source and updated by a sync job. Do not
send pull requests here; write to the Journzy support address on https://journzy.com/en instead.
